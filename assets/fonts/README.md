# Fonts

The app uses **Thmanyah Sans**. The font files are **not** in this repository: the
Thmanyah font license does not allow the files to be uploaded or hosted anywhere
other than the official site.

To build the app, download the font yourself:

1. Get it from the official page: https://thmanyah.com (font download, free).
2. Copy these five files from `thmanyah typeface/thmanyahsans/otf/` into this folder,
   without renaming or editing them:
   - `thmanyahsans-Light.otf`
   - `thmanyahsans-Regular.otf`
   - `thmanyahsans-Medium.otf`
   - `thmanyahsans-Bold.otf`
   - `thmanyahsans-Black.otf`
3. Run `flutter pub get`, then fully restart the app.

`*.otf` files in this folder are ignored by git.
